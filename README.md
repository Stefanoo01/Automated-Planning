# Autonomous Salvage ROVs in the Hadal Research Base "Abyssus"

> Free Choice Assignment for the course **Automated Planning: Theory and Practice**
> University of Trento — A.Y. 2025/2026

This repository contains the complete implementation of the **Abyssus** planning domain, developed for the Free Choice Assignment of the Automated Planning course.

The project models a team of autonomous underwater Remotely Operated Vehicles (ROVs) operating inside a damaged deep-sea research facility. Across five progressively more complex tasks, the same scenario is solved using different planning paradigms, ranging from classical planning to ROS2 execution with PlanSys2.

The assignment can be found in the `assignment.pdf` file, while the report with the implementationd etails and results can be found in `report.pdf`.

## Project Structure

The code is split based on task directories. Each task directory contains the files required to reproduce the corresponding experiments. Each task directory contains a `domain.pddl` file, one or more `problem.pddl` instances, a `run.sh` script for executing the selected planner, and the resulting plan(s) generated by the solver, stored in `solution.plan`.

```text
.
├── task1/                          # Classical Planning
├── task2/                          # Multi-Agent Planning
├── task3/                          # Hierarchical Task Networks (HTN)
├── task4/                          # Temporal Planning
├── task5/                          # PlanSys2 + ROS2
│   ├── plansys2_abyssus_base/      # ROS2 implementation
│   ├── Dockerfile                  # Docker image for Task 5
│   ├── start_docker.sh             # Launch script for Task 5
│   └── ...
├── Dockerfile                      # Docker image for Tasks 1–4
├── start_docker.sh                 # Launch script for Tasks 1–4
└── ...
```
Notice that tasks 1-4 need to be runned inside the Dockerfile found in the root directory, while task 5 has a dedicated Dockerfile, which can be found in `task5/Dockerfile`. To improve the usability, the repository provides a `start_docker.sh` script. The script automatically builds (or reuses) the required Docker image and launches a container with the repository mounted inside `/project`.

# Running the Project

Each task contains its own domain and problem files together with any solver-specific resources.

In general:

1. Choose the desired task.
2. Run the corresponding planner.
3. Inspect the generated `.plan` files.

For **Task 5**, follow the instructions contained in:

```text
task5/README.md
```

which explains how to launch the Docker container and execute the PlanSys2 simulation.
